
# 📖 Glossário de ETFs

| Conceito | Significado |
|---|---|
| ETF | Exchange Traded Fund |
| TER | Total Expense Ratio |
| AUM | Assets Under Management |
| ISIN | Identificador internacional do ativo |
| Acc | Accumulating |
| Dist | Distributing |
| Tracking Difference | Diferença entre ETF e índice |
| Replicação Física | Compra dos ativos do índice |
| Replicação Sintética | Uso de instrumentos financeiros para acompanhar o índice |
| Holdings | Ativos existentes no ETF |
| Overlap | Sobreposição de ativos entre ETFs |
| Drawdown | Queda desde um máximo anterior |
| Volatilidade | Medida da variação dos preços |
| DCA | Dollar-Cost Averaging |
| Valuation | Avaliação relativa do preço de um ativo |
